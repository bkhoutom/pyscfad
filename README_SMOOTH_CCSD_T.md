# DLNO-CCSD/CCSD(T) documentation

The consolidated [DLNO-STC user guide](pyscfad/dlno_stc/README.md) covers domain
MP2 and DLNO-CCSD/CCSD(T) energies and forces, current defaults, controls,
quadratures, integral storage, MPI, checkpoints, builds and runnable examples.

For derivations and implementation details, see
[smooth LIS frames, Laplace triples and response](doc/source/user_guide/smooth_lis_triples.md).
[SCF/DF performance notes](README_SERIAL_DF_SCF.md) and the
[water-cluster example](examples/dlno_stc/README_water_16.md) cover their
respective execution settings.
